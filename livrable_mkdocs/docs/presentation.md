# Présentation du projet

La soutenance HRNova est disponible en PowerPoint, avec **19 diapositives** et des notes orateur intégrées.

[**Télécharger la présentation HRNova**](presentation/HRNova_Soutenance_Infographie_2026-11-10.pptx){ .md-button .md-button--primary }

Le support couvre le contexte, le choix et les métriques du modèle, l’API et Pydantic, la couverture des tests, PostgreSQL, Git, GitHub Actions, les secrets, Hugging Face, le bilan et les améliorations. Les chiffres de la recette sont datés du 10 novembre 2026 : 263 tests réussis et 100 % des lignes couvertes sur le périmètre mesuré.

Les autres onglets de ce site donnent les détails et les commandes pour démontrer le projet en local. Le [dépôt GitHub](https://github.com/samuelGabbai/P5_Futurisys) contient le code source.
